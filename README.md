# -CALFIN
1° Projeto de programação da matéria do Seminário Integrador II, meu projeto que tem como objetivo desenvolver um aplicativo funcional para auxiliar em cálculos financeiros do dia a dia e aplicar conhecimentos de programação e matemática financeira com interface gráfica, capaz de realizar cálculos de juros, juros, aumento e desconto salarial.
